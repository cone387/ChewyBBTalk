# ChewyBBTalk Desktop 0.2.3

- 修复编辑框鼠标交互受全屏悬浮层影响的问题：编辑、设置、登录窗口打开时暂停悬浮层及鼠标转发，关闭后恢复。
- 恢复编辑框、设置和登录窗口的透明圆角，保留稳定的窗口尺寸。
- 首次打开在当前屏幕居中；拖动后记住各窗口的位置，关闭重开或重启后恢复。
- 更新通道未发布、网络故障、更新包校验失败分别提示。

Windows 0.2.1/0.2.2 用户可在“设置 → 关于”检查更新，下载后保存草稿并重启安装。0.2.0 及更早版本请手动下载安装包。

验证：41 项单元测试、7 项 Electron 联调；包含 GPU 开启下的可见窗口鼠标交互、圆角像素验证、位置恢复和 100%/125%/150% 缩放。
