## ADDED Requirements

### Requirement: 附件独立失败恢复
Web SHALL 保留每个附件的上传状态和成功结果，并允许失败项单独重试或移除。

#### Scenario: 批次部分失败
- **WHEN** 两个文件一个上传成功、一个失败
- **THEN** 成功项保留，失败项显示文件名、错误和重试入口
- **AND** 重试不再次上传成功项

#### Scenario: 上传未完成
- **WHEN** 存在上传中或失败待处理项
- **THEN** 禁止发布，并说明需要完成上传或移除失败项

#### Scenario: 移除上传项
- **WHEN** 上传中移除文件或卸载编辑器
- **THEN** 中止请求，迟到结果不得重新出现在编辑器

### Requirement: 发布失败保留输入
Web SHALL 在发布或更新失败时保留正文、标签、附件、可见性并显示可操作反馈。

#### Scenario: 失败后重试
- **WHEN** 发布请求失败
- **THEN** 内容仍在编辑器且可以手动重新提交
- **AND** 成功提交后才清空新建表单

### Requirement: 响应式编辑验收
Web SHALL 让小屏及横屏的附件操作、长内容和弹窗可见且可滚动操作。

#### Scenario: 长内容与附件
- **WHEN** 375px 小屏或横屏编辑长内容和附件
- **THEN** 文本可滚动，附件移除无需悬停，页面不横向溢出

#### Scenario: 主题及字体走查
- **WHEN** 使用深色系统偏好、放大字体和减少动态效果
- **THEN** 记录实际支持边界并检查表单、错误和弹窗可读性
