## ADDED Requirements

### Requirement: 窗口和设置行为一致
桌面 MUST 默认不置顶编辑、登录和设置窗口，支持编辑框固定置顶，按目标显示器定位，真实保存服务器设置，统一各处应用图标。

#### Scenario: 副屏打开和保存设置
- **WHEN** 用户在副屏打开编辑框并修改服务器设置
- **THEN** 编辑框在副屏可见范围内，普通窗口可覆盖它，设置重开仍保留，切换服务器不会沿用旧账号凭证

### Requirement: 草稿与中文输入可靠
桌面 MUST 保存文字和附件草稿，关闭重开、重复唤起、上传中关闭不丢失已接收内容，中文输入法选词回车不得发送。

#### Scenario: 输入后立即关闭
- **WHEN** 用户输入中文、附加图片并立即关闭后重开
- **THEN** 草稿和附件状态恢复，选词回车未创建帖子

### Requirement: 附件上传预览与权限
桌面 SHALL 显示即时图片预览和逐项上传状态，提供失败重试，并支持自定义服务器；私密附件 MUST 要求鉴权，公开文章 SHALL 可正常展示附件。

#### Scenario: 批量上传部分失败
- **WHEN** 两个附件中一个上传失败
- **THEN** 成功项保留，失败项可重试，关闭重开后仍可恢复，发布不得静默遗漏失败项

#### Scenario: 私密截图跨端查看
- **WHEN** 用户发布私密截图后在 Web 查看
- **THEN** 作者可查看完整附件，匿名访问被拒绝，文章改公开后可公开预览

### Requirement: 可重复依赖安装
后端 MUST 使用 PyPI chewy-attachment 0.5.2 及 django-s3 扩展，锁文件不得再依赖该项目 Git 地址。

#### Scenario: 干净安装
- **WHEN** 使用锁文件安装后端依赖
- **THEN** 从包索引安装附件包，本地与 S3 接口回归通过
