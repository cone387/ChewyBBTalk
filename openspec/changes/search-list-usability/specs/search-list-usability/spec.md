## ADDED Requirements

### Requirement: 筛选状态可见且可清除
列表 SHALL 展示关键词、标签、日期和附件的当前筛选条件，支持单项移除和全部清除。

#### Scenario: 移动端关闭筛选面板
- **WHEN** 用户设置条件并关闭筛选面板
- **THEN** 列表仍显示当前条件，移除其中一项保留其他条件

#### Scenario: 清除所有条件
- **WHEN** 用户点击全部清除
- **THEN** 关键词、标签、日期与附件条件均清空，列表重新加载全部记录

#### Scenario: 筛选无结果
- **WHEN** 任意筛选条件下没有记录
- **THEN** 页面显示没有匹配结果并提供清除操作，不显示账号暂无内容

### Requirement: 安全的搜索高亮
Markdown 正文 SHALL 高亮可见文本中的搜索命中，保留原有语义与安全渲染。

#### Scenario: 搜索词包含特殊字符
- **WHEN** 用户输入中文、英文或正则特殊字符
- **THEN** 按字面匹配高亮，不执行输入、不改变链接目标或注入 HTML

#### Scenario: 清空搜索
- **WHEN** 用户移除关键词条件
- **THEN** 正文恢复普通渲染，原有 Markdown 内容不变

### Requirement: 可复现的列表性能证据
迭代 SHALL 提供隔离数据上的分页和搜索性能报告，并验证优化不会破坏权限及结果正确性。

#### Scenario: 代表性数据测量
- **WHEN** 运行基准脚本
- **THEN** 在临时数据库生成代表性数据，输出数据规模、环境、p50/p95、查询数和响应条数，不写入现有数据库

#### Scenario: 查询优化验证
- **WHEN** 根据测量调整查询
- **THEN** 保留前后测量结果，并通过多标签、多评论、账号隔离和分页回归
