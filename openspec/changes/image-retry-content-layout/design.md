## Context

图片组件改变 loading 状态不会重新运行请求，且 Blob 下载完成即调用 onLoad，尚未确认可解码。Markdown 无语言代码块与表格缺少独立滚动容器。

## Goals / Non-Goals

目标：图片失败有真实恢复路径，重渲染不重复请求，长内容在小屏可阅读。非目标：阅读入口重构、PWA、全站深色主题或自动部署链路改造。

## Decisions

### 方案选型

重试计数驱动加载；重试先失效对应缓存，再请求。请求 effect 使用回调 ref，避免调用方内联回调引发循环。图片 DOM onLoad/onError 表示解码结果；切换 src 重置内部状态，卸载释放 Object URL 并忽略迟到结果。

Markdown 外层允许长词换行，pre 和 table 包裹容器单独横向滚动，无语言代码块同样生效。原有清洗策略保留。

### 未采纳方案及原因

不自动无限重试，以免损坏资源持续请求；不清空整个图片缓存，只失效目标资源；不以隐藏整个页面溢出替代局部滚动。

## Risks / Trade-offs

客户端缓存失效不能修复服务器资源损坏；持续错误仍需提示重试。浏览器走查不能代表原生真机或所有 Web 引擎。当前部署失败源于远端 TLS，单独记录状态。
