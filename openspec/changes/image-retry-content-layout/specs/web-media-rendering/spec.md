## ADDED Requirements

### Requirement: 图片失败可恢复
图片组件 SHALL 提供可键盘访问的重试按钮，重新获取失败资源并根据图片解码结果显示状态。

#### Scenario: 下载失败重试
- **WHEN** 图片下载失败后点击重试
- **THEN** 发起新请求，成功显示图片，自定义占位图同样提供重试

#### Scenario: 损坏图片
- **WHEN** 下载成功但图片解码失败
- **THEN** 显示失败入口，重试时失效该图片缓存

#### Scenario: 切换和卸载
- **WHEN** 请求未完成时切换图片或卸载组件
- **THEN** 迟到结果不得回写，Object URL 被释放，回调变化不引发重新下载

### Requirement: 长内容局部滚动
Markdown SHALL 在小屏约束长链接、代码和表格宽度。

#### Scenario: 宽内容
- **WHEN** 375px 页面显示长链接、带或不带语言的代码块、宽表格
- **THEN** 长词换行，代码和表格局部滚动，卡片不超过视口
