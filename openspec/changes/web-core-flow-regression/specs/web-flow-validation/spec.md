## ADDED Requirements

### Requirement: 隔离业务回归
Web 回归 SHALL 使用临时数据库和媒体目录，且不得复用既有本机服务或生产数据。

#### Scenario: 本地与 CI 运行
- **WHEN** 开发者执行浏览器回归命令
- **THEN** 自动启动隔离后端和 Web，测试结束停止服务并生成报告

### Requirement: 关键操作持久性
回归 SHALL 在桌面和小屏覆盖登录、发布、编辑、搜索、删除撤销及最终删除。

#### Scenario: 记录完整生命周期
- **WHEN** 用户发布、编辑、搜索并撤销删除记录
- **THEN** 刷新后记录内容正确且仍存在，最终删除完成后刷新不再出现

#### Scenario: 登录错误
- **WHEN** 用户输入错误密码
- **THEN** 保持在登录页并显示错误，允许改正后重试
