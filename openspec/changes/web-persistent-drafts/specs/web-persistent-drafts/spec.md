## ADDED Requirements

### Requirement: 持久化完整草稿
Web SHALL 自动保存并恢复正文、标签、可见性、附件以及待重试的文件。

#### Scenario: 刷新恢复
- **WHEN** 草稿保存完成后刷新或离开并返回页面
- **THEN** 恢复对应草稿且未完成文件可手动重试

### Requirement: 草稿隔离与生命周期
草稿 SHALL 按服务器、账号和编辑记录隔离，发布成功或明确清除时才删除。

#### Scenario: 隔离恢复
- **WHEN** 切换账号或编辑另一条记录
- **THEN** 不显示其他账号或记录的草稿

#### Scenario: 发布或清除
- **WHEN** 发布失败
- **THEN** 保留草稿
- **AND** 发布成功或确认清除后，旧写入不得恢复已删除草稿

### Requirement: 保存反馈与保护
Web SHALL 显示恢复、保存和错误状态，并在未落盘时提示关闭风险。

#### Scenario: 存储或并发错误
- **WHEN** 浏览器拒绝存储或其他标签页已修改草稿
- **THEN** 保留当前输入并显示失败，不误报已保存

#### Scenario: 离开未保存页面
- **WHEN** 当前输入尚未保存且关闭或刷新页面
- **THEN** 注册浏览器离开提醒并尝试刷新待保存快照
