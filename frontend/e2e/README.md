# Web 浏览器回归

依赖：Node.js 20+、Python 3.13、uv。先在 `backend/` 执行 `uv sync --frozen`，在 `frontend/` 执行：

```sh
npm ci
npx playwright install --no-shell chromium
npm run test:e2e
```

CI/Linux 首次安装浏览器可使用 `npx playwright install --with-deps --no-shell chromium`。

- 测试启动回环地址 `127.0.0.1:18020` 的 Django 和 `127.0.0.1:14175` 的 Vite；端口被占用时失败，不复用既有服务。
- 后端使用系统临时目录内的新 SQLite、媒体、静态文件和测试密钥，每条测试通过真实注册接口准备独立账号。不会连接本机开发数据库。
- 使用真实 API，覆盖桌面 1440×1000、小屏触控 375×812：错误登录后重试、发布、编辑、搜索、删除撤销、最终删除和连续删除。
- 断言刷新后的持久状态。正常 feed/undo 截图保存在 `test-results/`，失败时另外保留 trace 和截图。
- 查看报告：`npx playwright show-report`；CI 保留报告 7 天。
- 测试通过 Vite 开发服务器访问 Web，生产构建由独立 `npm run build` 检查；不替代 Nginx 部署、WebKit/Firefox、真机键盘和原生功能验收。
- 正常退出清理临时数据；Windows 强制结束进程可能留下 `chewybbtalk-e2e-*` 临时目录，可按系统临时文件策略清理。

## 附件与 UI 回归补充

`attachment-recovery.spec.ts` 使用真实临时后端完成上传、发布和更新；通过定向拦截制造 413、断网和 500，验证部分成功保留、逐文件重试、发布失败保留以及防窥页面同样保留输入。

UI 走查覆盖 375px 竖屏、812px 横屏、根字号 24px、深色系统偏好和减少动态效果。Web 当前仍为浅色主题，深色偏好测试不代表已实现深色主题；浏览器模拟不代替原生真机键盘、语音或后台恢复验收。导入弹窗采用验证结果 fixture，仅检查布局和退出，不执行导入。

失败文件现由本地草稿一起保存在 IndexedDB，保存完成后刷新或导航返回可手动重试。移除上传中项会中止浏览器请求，但不保证服务端已接收的文件回滚。不自动发布或自动重传文件。

`media-layout.spec.ts` 补充图片下载失败、损坏图片缓存的手动恢复，以及长链接、无语言/带语言代码块和宽表格的局部横向滚动。图片上传使用真实后端，下载响应按次注入断网、损坏内容和有效 PNG，验证实际浏览器解码；这些用例不代表生产媒体服务器可用性验收。

## 本地草稿回归

`drafts.spec.ts` 使用真实 IndexedDB 和 Django，覆盖正文/标签/可见性/已上传附件/失败文件的刷新恢复，重试后下载文件核对字节，发布失败保留及成功清理，账号与记录隔离，导航恢复、跨标签页清除冲突、存储拒绝和旧记录更新提示。新建与编辑同时打开时，发布只创建新记录。

`persistent-draft.test.ts` 补充服务器键隔离、卸载提交最后输入、写入与清除串行、离开提醒及存储重试。草稿仅存于当前浏览器，清理浏览器数据会丢失草稿；这不等于服务端同步或备份。

## 备份恢复回归

`backups.spec.ts` 在桌面和小屏通过真实 API 创建记录、上传附件和添加评论，创建并下载完整 ZIP，再导入独立账号，核对统计、记录内容和附件字节。另覆盖创建失败后重试、下载断网，以及旧格式导入的部分完成报告。`backup-list.png` 保留备份列表截图；这不替代生产环境大体积备份演练。

## 搜索与筛选回归

`search-filters.spec.ts` 使用真实后端，在桌面和小屏验证关键词高亮、日期/附件条件摘要、单项移除、全部清除（含标签）及日期筛选无结果。高亮单元测试验证字面特殊字符、中文、链接、代码与 HTML 安全。

Vite 测试服务始终以非交互模式运行（仅其子进程 `CI=true`），避免本地 stdin 结束关闭服务；Playwright 的重试配置仍由运行测试时的 CI 环境决定。
