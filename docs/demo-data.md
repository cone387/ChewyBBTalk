# 演示数据

根 `.env` 中的 `CREATE_DEMO_USER=true` 在首次初始化时创建普通账号 `demo / demo123`。
初始数据为 240 条记录、19 个标签、320 条评论、18 个附件及一个专用本地存储配置。
已有账号原先添加或删除过数据，补充后的总数可能不同。

## 补充已有账号

```bash
cd backend
uv run python -m cli seed-demo
```

单容器：`docker exec -w /app/backend chewy-bbtalk python -m cli seed-demo`。
Compose：`docker compose exec backend uv run --frozen --no-dev python -m cli seed-demo`。

该命令显式创建或补充 demo，不依赖自动初始化开关。账号已存在时保留其密码。
使用稳定场景编号避免重复插入，保留用户修改过的记录和评论；再次执行会补回已删除的预置记录。
普通启动时的 `init` 不补回已删除记录。该命令只针对 demo，不修改其他用户数据。

| 场景导航 | 置顶的“演示场景导航” |

| Markdown | 多级标题、粗斜体、删除线、引用、列表、任务清单、代码块、宽表格、超长链接 |
| 标签 | 无标签、多标签、长名称、中英文与 Emoji、“暂未使用”零记录标签 |
| 图片 | 搜索“图场景”：1/2/3/4/6/9 图、横图、竖图、全景比例、半透明 PNG |
| 音视频 | 搜索“视频场景”“音频附件场景”：两秒 MP4、一秒 WAV（当前网页音频以文件下载展示） |
| 文件 | 搜索“文档场景”：PDF、TXT、CSV、JSON、ZIP，含中文、空格与特殊字符文件名 |
| 混合附件 | 同一记录中的图片、视频、音频、文档 |
| 可见性 | 公开、私密、公开置顶、私密置顶；私密图片和 PDF 的匿名访问受限 |
| 评论 | 无评论、单条、多条、24 条密集评论、长评论、换行及 Emoji |
| 时间与分页 | 搜索“时间线”；今天、昨日、上周、上月、去年，默认 100 条/页，共三页 |
| 编辑与排序 | 搜索“已编辑场景”：旧创建时间、较新更新时间 |
| 来源与地点 | Web / iOS / Android / Desktop 来源和坐标信息 |
| 搜索 | 咖啡、coffee、周报、FastAPI、blue sky、100%、under_score |
| 存储与备份 | 真实附件及 local 存储配置可用于迁移预览、导出、备份与恢复测试 |

附件完全本地生成或随代码打包，不依赖图片网站、S3、网络下载或运行时 ffmpeg。
“演示素材（本地）”仅关联预置附件，不改变账号已有活动存储设置。
公开样例使用演示内容；私密样例仅 demo 可访问。

网络超时、上传失败、限流、账号间越权和 S3 故障需要交互或外部状态，不能靠静态数据呈现，继续由对应自动化测试验证。
