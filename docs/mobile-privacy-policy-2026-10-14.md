# 移动端防窥策略与覆盖情况（1.3.11）

> 1.3.12 调整：按用户要求移除各页面独立锁按钮，手动锁定继续使用首页倒计时点击入口（长按进入防窥设置）。下文独立锁按钮的描述仅记录 1.3.11 历史实现，其余隐私策略保持不变。

本轮修正 1.3.10 将后台遮挡、内容锁定和截图限制混在一起的过度保护。短暂切换应用不再使整个历史页面进入未就绪状态，保留页面、滚动和输入；保护发生在需要隐藏内容或重新验证身份的时机。

本文是代码与自动化验收记录，不代表 iPhone / Android 真机全部场景已通过。原有页面、分享及数据操作的完整审计见 [1.3.10 审计](mobile-privacy-audit-2026-10-14.md)，生命周期与截图策略以本文为准。

## 默认行为

| 场景 | 1.3.11 行为 | 是否要求重新解锁 |
| --- | --- | --- |
| 短暂切换到其他应用再返回 | iOS 原生窗口模糊遮挡后台预览，包含原生 Modal；返回时先完成锁定判断再撤去遮挡，保留当前页面与输入 | 未超过无操作时长、未检测到设备锁屏时不要求 |
| 拉下通知中心、控制中心、系统验证短暂失焦 | 临时遮住内容；不因单独的 inactive 事件销毁页面、取消正常身份验证 | 不因失焦本身要求；已到超时仍锁定 |
| App 被关闭或系统回收后重新启动 | 历史内容先锁定；本次启动刚完成账号密码登录则避免紧接着重复验证 | 默认要求；可关闭“启动时锁定” |
| 设备锁屏后返回 | 记录原生锁屏信号及版本，恢复时检查后台期间错过的事件 | 默认要求；可关闭“设备锁屏后锁定”；有下述系统边界 |
| 无操作超过设定时长 | 锁定历史内容，后台时间也计入，不把进入后台算作用户操作 | 要求；默认 5 分钟，沿用用户原设置 |
| 临时把手机交给别人、旁边有人 | 导航或当前弹窗的锁图标可立即锁定；不依赖倒计时是否显示 | 手动锁定后要求；启用自动锁定时提供入口 |
| 截图、录屏、投屏 | 截图录屏限制默认关闭，用户可单独开启；不再强制开启导致黑色预览 | 不因此要求 |
| 音视频播放时切后台 | 暂停播放，保留页面；后台期间完成的下载或加载不自动开始播放，返回也不自动继续 | 按超时 / 设备锁屏判断 |
| 读取隐私设置失败或一直不返回 | 最迟 3 秒后显示内容已锁定的错误与重试入口，不持续显示空白页 | 保持锁定，重试配置读取 |
| 外观、关于、无敏感内容的高级设置入口 | 不单独要求历史内容解锁；其下存储、缓存、数据等敏感页面仍有边界 | 不因普通外观设置要求 |

“隐藏后台预览”和“阻止截图与录屏”独立于“启用自动锁定”。既有用户升级后保留原超时、倒计时等设置；新增项默认启动锁定、设备锁屏锁定、隐藏后台预览开启，截图录屏限制关闭。

## 内容和操作覆盖

- 首页、搜索、标签、日历、详情、评论、图片 Modal、草稿、同步队列、个人资料、账户安全、标签编辑、存储与数据页面沿用统一锁定边界。真正锁定时隐藏历史及敏感弹窗；短暂后台时保留页面状态。
- 编辑旧记录保留草稿和输入，真正锁定时隐藏编辑器；锁定时允许的新建入口不能读取旧记录。音视频、录音以及键盘分别执行已有的锁定收尾。
- 分享、复制、地图、导出、导入、批量操作等继续校验账号与隐私版本。进入后台使未完成的对外内容交付失效，即使返回后仍解锁，旧异步回调也不能悄悄继续交付。已经授权保存的后台同步不因此删除或撤回。
- 小组件 JS 数据层在未登录、未就绪、锁定或后台暂停期间输出空内容，恢复后重新同步；本仓库没有已发布的原生 Widget 扩展。
- 快速锁定入口覆盖普通导航、首页标签栏、批量工具栏、编辑器、评论弹窗、标签编辑弹窗和图片查看器；隐藏倒计时不再让手动锁定入口消失。
- 快速 background → active 事件被 React 合并时也会重新确认并撤去原生遮罩，避免回到 App 后一直被遮住。

## 平台和外部出口边界

1. iOS 使用公开的 protected-data 通知识别设备锁屏，不等同于每次按电源键都立即收到事件；没有设备密码、极短锁屏或系统事件时序可能影响识别。因此不能声称任意设备锁屏都 100% 立即触发。冷启动与超时锁定仍独立有效。[Apple 文档](https://developer.apple.com/documentation/uikit/uiapplication/protecteddatawillbecomeunavailablenotification)
2. Android 使用屏幕关闭广播及 Keyguard 状态；系统可能延迟或合并后台广播。Android 13+ 独立隐藏多任务预览使用系统接口，最终占位样式由系统决定，可能为空白；Android 12 及以下没有在不限制截图的前提下提供同等原生预览保证。[Android Activity](https://developer.android.com/reference/android/app/Activity#setRecentsScreenshotEnabled(boolean))、[广播说明](https://developer.android.com/reference/android/content/Context#registerReceiver(android.content.BroadcastReceiver,%20android.content.IntentFilter))
3. 可选截图保护沿用 Expo ScreenCapture，具体效果受系统、投屏方式和原生 Modal 影响；开启后可能出现系统黑色预览。Web 没有等价的系统截图禁止能力。[Expo ScreenCapture](https://docs.expo.dev/versions/v54.0.0/sdk/screen-capture/)
4. 已交给系统分享面板、剪贴板、外部浏览器 / 地图或接收方的内容，不能通过 App 后续锁定撤回；主动导出的备份也不受 App 解锁界面保护。外部相机、屏幕已经解锁时旁人的视线没有软件绝对防护。
5. 当前没有启用推送正文、系统搜索索引、Live Activity 或原生 Widget；未来新增时要单独审计。磁盘加密、服务器鉴权和设备被破解不属于本次显示防窥验收。

## 验证与真机复验

自动化覆盖设置读写失败 / 迟到返回、启动与设备锁定、账号切换、后台未超时保留页面、超时锁定、延迟验证失效、遮罩撤除竞态、截图保护开关串行化、播放器后台暂停及小组件清理。原生插件对固定依赖版本及源代码哈希校验，验证旧补丁升级、重复执行和未知源码拒绝。

仍需设备验收：iPhone 普通页面与 Modal 的多任务缩略图、连续快速切换、下拉控制中心、Face ID、锁屏立即解锁和长时间锁屏、截图 / 录屏 / 投屏；Android 版本差异及真实播放行为。本环境没有连接手机，不能把单元测试或 EAS 编译写成已完成真机验收。

最终测试、构建和 TestFlight 状态见 [发布验收记录](../mobile/RELEASE_READINESS.md)。
