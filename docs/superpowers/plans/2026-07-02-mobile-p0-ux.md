# Mobile P0 UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve mobile perceived startup speed, restore mobile test confidence, and harden background privacy protection.

**Architecture:** Keep changes focused inside `mobile/`. Use cache-first data restoration for home feed, test-environment fixes for existing Jest failures, and a small native-safe screen-capture protection layer for Android privacy.

**Tech Stack:** Expo React Native, Redux Toolkit, Jest, `expo-sqlite`, `@react-native-community/netinfo`, optional `expo-screen-capture`.
