# 手机端成品质量与原生验收

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 全面修正手机端 Liquid Glass 适配的视觉和交互问题，完成原生运行验收、提交推送、部署及 TestFlight 更新。

**Architecture:** 保留现有 Expo / React Native 导航与业务架构。玻璃仅用于浮动操作层；普通内容与表单保持清晰表面。使用隔离的合成 API 数据运行实际 iOS 模拟器应用，验收不依赖修改生产数据。

**Tech Stack:** Expo SDK 54、React Native 0.81、React Navigation 7、Maestro、GitHub Actions macOS。

**Spec:** 用户要求全组件苹果液态玻璃风格及可交付质量；具体截图问题和已修正项见 `docs/mobile-liquid-glass.md`。

## 约束与视觉规范

- 系统字体；正文 16–17pt，页面标题 17pt/600，次要信息 12–13pt。可缩放文本不能被固定高度裁切。
- 使用当前主题语义色：浅背景 #F1F3F8、白色内容、蓝色主操作；深色使用对应主题表面。设置图标统一，危险操作才用红色。
- 主导航、返回、编辑、弹窗、表单、媒体、草稿、空/错/加载态全部检查；44pt 以上触控区域。
- 原生截图必须注明设备/系统/提交；模拟器不冒称物理 iPhone。Web 截图不证明原生键盘和玻璃效果。
- 不改变真实业务数据，不提交密钥、用户截图、缓存或构建产物。根目录保持整洁。
