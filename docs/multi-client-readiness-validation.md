## 本轮发现并修复

- Web 恢复原提交前确保后来输入已落盘；评论重试不清除后来输入。
- 原生恢复前保存完整编辑草稿，兼容旧正文；草稿未读完不允许发布，离开未加载界面不清除原草稿。
