# Web 控件规范

适用于 `frontend/` 的 React Web 页面，以桌面浏览器为主设计。窗口收窄时可以切换为紧凑布局；Expo 手机程序独立维护。新增页面和修复页面都按本规范验收。

## 布局边界

- 以桌面页面的信息密度、导航和操作为设计起点，不把手机页面放大作为 Web 页面。
- 1024px 及以上保留左侧导航；设置及子页使用同一桌面布局，表单和选项按可用空间分栏。低于 1024px 时允许纵向布局和紧凑导航。
- 桌面已有侧栏的页面不显示重复的返回顶栏、返回箭头或占位页眉，内容直接从页面标题开始；返回入口只在窄窗口收起侧栏后出现。记录详情页同样遵守。
- 左侧搜索框与标签列表共用滚动区域，底部账户区固定且不加顶部横线。标签列表仅支持单选切换，点击当前标签保持选中，点击“全部”恢复完整列表；记录编辑时仍可添加多个标签。
- 记录页保留搜索和标签；不擅自添加日期、附件、可见性、排序面板或条件摘要按钮。
- 防窥倒计时保留原有右下角悬浮位置：桌面距右侧和底部各 32px；窄窗口距右侧 16px、底部 80px，避开底部导航。不得擅自移动到顶栏或侧栏。
- 窄窗口适配不能反过来改变桌面入口、导航位置或业务流程。

## 视觉约束

- 内容优先。修复可用性不等于新增操作、给每个入口加底色，或把所有按钮做成同样醒目的方块。
- 标签右侧数量不使用独立背景或徽章底色，普通、悬停和选中状态均与整行背景一致。
- 点击范围与绘制范围分开：标签可以保留 44px 可操作范围，内部只绘制紧凑的标签文字和小关闭图标。
- 评论发送、存储卡片操作使用轻量文字入口；桌面评论删除在悬停或键盘进入该评论时呈现，触屏保留直接入口。
- S3 卡片的操作保持单行，不扩展为两排大按钮。必要时自然换行，不强行铺满卡片。
- 优先保留现有页面的密度与层级；增加常驻按钮前先确认它是否需要单独占位。

## 颜色与状态

- 主色使用 `--color-primary`（#2563eb），悬停使用 `--color-primary-hover`。
- 普通辅助文字使用灰度 500/600 或 `--color-muted`；小字号正文、时间、占位文字以至少 4.5:1 为检查目标。禁用状态与纯装饰不混同正文。
- 所有输入框点击或键盘聚焦后保持原有边框颜色、背景和阴影，不增加高亮边框、outline 或 ring。包括登录、搜索、评论、正文编辑器、账户与 S3 表单，以及原生输入框、下拉框；编辑器外层容器也不能通过 `focus-within` 变色。按钮等操作控件保留键盘焦点提示。
- 动画服从 `prefers-reduced-motion`。异步按钮禁用并显示明确的处理中反馈。

## 表单

- 优先使用 `Input`、`Textarea`、`Select`；原生控件需要特殊业务接口时使用 `app-input` 并落实同样的标签与状态关联。
- 标准输入：16px 字号、8px 圆角、灰度 200 边框、白色背景；至少 48px 高，目前文本和日期框自然高度为 50px。多行输入按内容增加高度。
- 标签使用 `app-field-label`，必须与字段关联。必填星号不能代替 `required`。
- 字段错误靠近字段，提供 `aria-invalid`、`aria-describedby`、红色边框和错误文字。定位第一个错误，修改字段时清除其旧错误。服务级错误用表单提示或 Toast，不把所有校验错误放到 Toast。
- `Input`/`Textarea` 可同时关联帮助文字与错误文字。密码与密钥不在错误提示中回显。
- 普通、hover、focus、error、disabled、readonly 状态在公共样式里维护，不在业务页面复制一套颜色/圆角。

## 按钮与操作范围

- 普通提交/次要/危险按钮使用 `Button` 或 `app-button` 对应变体；至少 44px 高、8px 圆角。
- 图标必须在按钮点击区域内水平、垂直居中，不能只增加按钮最小尺寸而保留图标靠左排列。
- 仅图标按钮使用 `app-icon-button`，至少 44×44px，并给按钮可访问名称。
- 菜单使用 `app-menu-item`，每行至少 44px，图标与文字起点一致；危险项使用 danger 变体。
- 下拉标签建议和标签移除同样保证 44px 操作范围。图标本身不需要膨胀到 44px。
- 复选框/开关按 label 的实际点击范围验收；滑块整体输入区域 44px，轨道可保持 8px。

## 图标

- UI 线性图标统一使用 `Icon`：24×24 viewBox、2 单位描边、圆角端点/连接。尺寸通过语义层级选择，禁止页面自定义描边。
- 已有图标尺寸：14px 辅助状态，16px 行内动作，18px 编辑器工具与桌面侧栏，20px 主要导航/设置入口；24px 以上用于大状态展示。
- 关闭、链接、编辑、删除、置顶、左右箭头使用命名图标，不能使用 `✕`、`×`、`‹`、`›` 等字体字符替代。特有图形可以向 `Icon` 提供路径，仍遵循统一样式。
- `Icon` 默认是装饰元素，由外围按钮/链接提供名称。独立传达信息时必须同时提供可读文本或说明。
- 品牌标识、空状态插画、加载 spinner 是独立图形，不强制相同描边。正文 Emoji 与标签 # 不属于操作图标。

## 明确允许的变体

|场景|允许差异|
|---|---|
|正文编辑器|透明、无边框输入面，输入框及外层容器聚焦均不变色，工具图标 18px|
|评论编辑器|`app-input--comment`，多行紧凑内边距，聚焦保持原样、8px 圆角；发送按钮固定最小 44px，不随文本框拉伸|
|搜索|桌面 44px/14px 字号、窄窗口 48px/16px 字号；8px 圆角，窄窗口浅灰背景|
|桌面标签侧栏|允许 36px 紧凑标签行；鼠标悬停或键盘聚焦时显示拖动把手；触屏保持直接入口|
|标签选择、媒体预览导航|可用胶囊/圆形容器表达选择或浮动导航，操作区域仍至少 44px|

## 验收

优先检查 1440px、1024px 桌面布局，再检查 768px、375px 窄窗口适配，实际点击、键盘 Tab/Escape、错误与禁用状态；区分 SVG 尺寸与按钮点击范围。不以截图看起来相似代替字段关联与键盘验证。报告和截图放 `frontend/test-results/`，测试使用独立数据。
