# 移动端首发验收

本轮变更：`mobile-launch-readiness`。实现与审核通过是两个阶段；此文档记录代码能力和发布前仍需实测的条件。

## 原生筛选与操作性能修复（2026-10-14）

原生运行时使用 Expo 引入的 `whatwg-url-without-unicode`，其 `URLSearchParams` 没有 `size` 属性；此前请求构造器据此判断查询参数是否为空，导致原生端日期、标签、搜索和分页参数被丢弃。现在检查序列化后的查询字符串，并直接用该兼容库做回归测试。日历缓存使用 v2 命名空间，避免继续展示旧版本缓存的错误全集；升级后需联网重新加载日历一次，不删除业务记录。

本轮调整：

- 标签导航已表达当前选择时，移除重复的标签筛选标题；关闭标签导航时仍保留可清除的筛选提示。再次点击当前标签保持选择，通过“全部”取消筛选。
- 移除首页右下角单独的录音悬浮按钮；保留新建按钮长按录音和编辑器语音入口。
- 切回首页时保留近期加载的列表；记录变更、恢复联网和回到前台仍刷新。失败请求不会被误判为新鲜数据，刷新期间发生记录变更会补一次刷新。
- 首页列表隔离评论弹层、搜索输入和隐私倒计时带来的无关重绘，卡片复用未变化的 Markdown 内容；移除切换筛选时的全局布局动画。评论输入聚焦不再等待弹层弹簧动画结束。
- 日历使用单个虚拟列表，按日期隔离请求并取消过期请求，去重分页；从详情返回保留已加载分页和阅读位置。
- SQLite 缓存改用异步 API，串行处理读写和事务；失败写入回滚，切换账号不会接收旧会话数据。
- 隐藏录音浮层不创建录音器或轮询状态；音视频卡片及编辑器音频预览在点击后才创建播放器。草稿内容不变时复用序列化结果。

可复现的性能回归覆盖：两条记录的测试夹具中，打开评论弹层和隐私倒计时更新不再重绘列表行；评论数量变化不重新解析未变化的正文；缓存评论首次显示由两次提交减为一次；草稿无关重绘的序列化遍历由 12 次减为 1 次；缓存批量写入期间允许界面事件执行。这些是自动化行为验证，不是设备帧率或耗时测量。

最终验证：102 套 / 1271 项单测、8 套 / 70 项界面集成、TypeScript 和 iOS/Android/Web 导出全部通过（产物位于 `mobile/dist/mobile-performance/`）。录音回归另覆盖旧录音销毁后再恢复播放音频模式、首次语音权限迟到时不启动已关闭的录音。根目录检查及 `git diff --check` 通过。现有覆盖率门槛仍未通过：行 94.20% / 要求 99%，分支 86.33% / 要求 93%，函数 87.20% / 要求 95%；未降低基线，不能称为 CI 全绿。

真机复验重点：有记录/空记录日期和跨月切换、第二页不重复、标签与搜索组合；连续切换导航和长列表滚动；点击评论后的键盘响应；包含图片/音频/视频的列表；录音权限首次授权和快速关闭重开；长文输入、离线恢复、账号切换及隐私锁。当前环境未连接 iPhone，浏览器控制连接也不可用，本轮尚未完成原生帧率、系统键盘手感和视觉截图验收。

## 三批移动体验迭代（2026-10-13）

本节覆盖下文首发阶段的旧限制：已增加持久化离线提交队列和编辑冲突处理，未上传附件也能点击保存并退出。此前的“只能手动重试”“未上传附件不能提交”不再适用于当前版本。

实现范围：搜索和筛选反馈、草稿目录、附件逐项重试、常驻语音入口、长文摘要、多图网格、紧凑评论、明确的公开状态、日历年月选择和原地分页阅读、账号隔离的日历缓存、持久化提交队列、恢复联网/前台自动同步、失败修订和冲突确认。无需新增部署配置或数据库迁移。

可靠性边界：只有点击保存的记录进入队列；未提交草稿不会自动发布。创建固定幂等键，编辑使用服务端版本条件；响应丢失可重试或核对结果。逐附件上传落盘，切换账号中断后续旧会话操作。草稿转移到队列时停止旧编辑器自动保存，瞬时清理失败、退出和连续相同内容的快速录入不会重复创建或误删下一份草稿。同步回执最多保留 20 条，成功后释放原始媒体快照；原生副本超过 24 小时且无引用时清理。

最终自动验收：单测 102 套 / 1240 项，界面集成 8 套 / 61 项全部通过；`npx tsc --noEmit`、`npx expo export --platform all --output-dir dist/mobile-ux --max-workers 2` 通过。iOS/Android 为 Hermes 导出，并非签名安装包。独立复审提出的重要问题已修复并复验；根目录检查和 `git diff --check` 通过。

浏览器实测使用隔离后端与临时账号，通过新建长文、离线保存、关闭浏览器上下文后恢复持久化队列、联网自动同步及日历原地阅读。375px 浅色、320px 深色截图已逐张检查，无横向溢出；截图位于忽略的 `mobile/test-results/mobile-ux/`。这是 Expo Web 验证，不等同于原生验收。

仍需真机验收：iOS/Android 系统键盘与安全区域、动态大字体/读屏、麦克风权限及连续录音、附件选择后切后台或系统强杀再启动。当前环境没有连接的 Android 设备，也没有可用 iOS 真机；上述项目没有标为通过。操作系统暂停应用时不承诺后台执行，队列在下次前台/启动继续。

## 本轮实现

- 输入停止 400ms 后保存草稿，切后台及卸载编辑器时立即尝试落盘；状态明确标注“本机”。编辑草稿按记录 ID 隔离并保留冲突检测版本。
- 草稿按服务器与账号隔离。保存后退出、丢弃修改、继续编辑使用不同动作；iOS Native Stack 使用 `usePreventRemove` 拦截返回。
- 原生附件先复制到应用文档目录，再上传。上传失败保留本地文件，恢复草稿后可重试；有未上传附件时不能提交记录。上传请求 60 秒超时。
- 未引用的原生附件副本在超过 24 小时后，于后续打开编辑器时清理；仍被草稿引用的副本保留。服务端确认删除账号后清理该账号的本机草稿及副本。
- Web 开发预览使用 data URL 保存附件，单文件最多 8MB；浏览器存储配额仍可能导致失败，此时明确提示。原生端不受此预览限制。
- 首页语音进入编辑器，可检查转写、附件和保存结果。仅附件记录也可保存；文字默认“附件记录”。
- 私密新建使用“保存”，公开操作明确说明正文与附件可能被未登录用户访问，并要求确认。
- 首页点击正文打开阅读页，编辑使用独立按钮；防窥锁定时阅读页及照片一起隐藏。
- 首次空态直接提供文字/语音入口；登录页折叠自建服务设置，读取服务端注册开关。
- 编辑器常用工具为图片、语音、标签和更多；拍照、视频、文件、位置和 Markdown 格式在更多面板。
- 账号安全页包含账号信息、修改密码、删除账号；登录页提供邮件找回。密码修改后旧访问令牌、刷新令牌及旧会话失效。
- 外观支持跟随系统；保留已有主题。语音卡片隐藏自动生成的文件名，引用块使用主题颜色。
- S3 和缓存移到高级设置；帮助页直接连接当前服务的支持页面。

## 后端升级与邮件配置

先备份，再在部署环境运行迁移：

```sh
cd backend
uv run python -m cli migrate
```

原生 Alembic 迁移建立完整业务表，或接管已完成旧版 `0009_password_recovery` 的数据库，保留凭证版本和恢复码摘要。默认不启用邮件找回；修改密码无需 SMTP。升级边界见 [后端说明](../backend/README.md)。

通过部署环境设置以下变量，不把真实密码写入仓库：

```dotenv
PASSWORD_RECOVERY_ENABLED=true
PASSWORD_RECOVERY_RATE=5/minute
EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_USE_TLS=true
EMAIL_USE_SSL=false
EMAIL_HOST_USER=your-smtp-user
EMAIL_HOST_PASSWORD=your-smtp-secret
DEFAULT_FROM_EMAIL=ChewyBBTalk <noreply@example.com>
```

SMTP 465 通常使用 `EMAIL_USE_SSL=true`、`EMAIL_USE_TLS=false`；具体以发信服务配置为准。恢复邮件通过 Python `smtplib` 发送，保留现有 `EMAIL_*` 环境变量。

发信配置完成后，使用测试账号验证送达与垃圾邮件情况，再开启生产找回入口。请求需同时匹配用户名和账号邮箱，响应不透露账号是否存在。恢复码 15 分钟有效，保存摘要，单次消费；邮箱或凭证版本变化后失效。邮件失败日志不输出验证码或发信凭证。

恢复端点同时按直接连接地址和用户名限流，默认与现有认证限流一样使用进程内限流器。多进程部署在可信反向代理配置统一请求限制。
